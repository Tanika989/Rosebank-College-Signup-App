## Purpose of the App
The Rosebank College Signup App is designed to allow new students to create an account to access college services. The app solves the problem of manual registration by providing a simple, mobile-friendly platform where students can register using their personal details and student email.

The main goal of the app is to:
- Provide a secure and user-friendly registration process for Rosebank College students.
- Validate student information to ensure only legitimate students register.
- Serve as the entry point for future features like viewing timetables, results, and learning materials.

## Who is the App For?
This app is for new and prospective students of Rosebank College who need to create an account on the college mobile platform.

## Key Features
1. **Full Name Field:** Captures the student's full name.
2. **Student Email Validation:** Only accepts valid email formats and checks for Rosebank student email.
3. **Secure Password Creation:** Includes password and confirm password with validation to prevent errors.
4. **Input Validation:** Shows error messages if fields are empty or passwords don't match.
5. **Modern UI:** Built with Jetpack Compose using Rosebank College branding colors for a professional look.

## Technology Used
- **Language:** Kotlin
- **UI Toolkit:** Jetpack Compose
- **Design System:** Material Design 3
- **IDE:** Android Studio

## How The App Works
1. User opens the app and sees the signup screen.
2. User enters Full Name, Email, Password, and Confirm Password.
3. App validates all fields are filled and passwords match.
4. On successful validation, user can proceed to login / dashboard (future implementation).
